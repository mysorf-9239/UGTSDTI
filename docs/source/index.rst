UGTSDTI Documentation
=====================

UGTSDTI is a research-oriented framework for binary drug-target interaction prediction
under warm-start and cold-start settings.

The current implementation focuses on:

- teacher-student modeling
- knowledge distillation
- uncertainty-gated fusion
- explicit `S1-S4` benchmark scenarios
- reproducible slot-based experiment configuration
